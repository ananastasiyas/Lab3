# Лабораторная работа № 3 - Доска публикаций

## Запуск

Откройте `index.html` в браузере с доступом к интернету. Сервер и база данных не нужны.

## Реализовано

- Загрузка 5 публикаций через GET, `fetch` и `async/await`.
- Создание публикации через POST с JSON и проверкой непустых полей.
- Вывод данных через DOM и `textContent` без перезагрузки страницы.
- Сообщения о загрузке, успехе и ошибках; повторная попытка после ошибки.

## Проверка

1. Нажать «Загрузить публикации»: ожидаются 5 заголовков и текстов.
2. Отправить пустые поля или пробелы: ожидается ошибка без запроса.
3. Ввести заголовок и текст и отправить: ожидаются сообщение об успехе, заголовок и ID из ответа.
4. Временно заменить адрес GET в `app.js` на `https://jsonplaceholder.typicode.com/postz`: ожидаются ошибка HTTP 404 и повторная доступность кнопки. После проверки вернуть адрес обратно.

Проверены синтаксис JavaScript и комплектность файлов. Проверки запросов в реальном браузере нужно выполнить при запуске.

**ВАЖНО** JSONPlaceholder имитирует создание публикации, но не сохраняет её постоянно.
